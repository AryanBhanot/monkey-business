# Userscripts

Organize scripts by the primary website they target:

```text
userscripts/
	example.com/
		hide-promoted-posts.user.js
	multi-site/
		useful-browser-tweak.user.js
```

Use lowercase hostnames for website directories and descriptive kebab-case filenames ending in `.user.js`.

Every script should include its userscript metadata block as the first content in the file.
